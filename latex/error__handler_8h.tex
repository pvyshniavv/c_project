\doxysubsection{Detailed Description}
Errors\textquotesingle{} constants, their definition and function(handle\+\_\+error) that acts accordingly to the error type. 

Every error that can be present in our program is listed here. Every error has its unique id (e.\+g 1, 2, 25). IDs from 1-\/10 correspond to general and common errors. IDs that start from digit 2 correspond to errors related to files.

\begin{DoxyAttention}{Attention}
As the project grows, more errors appear. When they do, make sure that you use this list and add every single error here. When you add new error constants, don\textquotesingle{}t forget to add description to them. 
\end{DoxyAttention}
\begin{DoxyWarning}{Warning}
NEVER USE RAW NUMBERS AS ERROR TYPES! 
\end{DoxyWarning}
